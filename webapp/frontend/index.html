EcoLang Compiler

This page runs source code through the EcoLang compiler (a C-subset, energy-aware compiler) and displays its optimization statistics and energy analysis, alongside the generated pseudo-assembly.

About this project

EcoLang is a small, hand-written compiler for a restricted subset of C, built in C++17 as a Compiler Design course project — not a full C compiler. It supports int/void functions with parameters, declarations, assignment, arithmetic, printf, return, if/else, while, for, comparisons, and function calls including recursion. It was migrated in three phases from an original toy language (let/print/repeat...end) to this C-like subset: first the basic statement forms, then control flow and comparisons, then functions and recursion.

Every optimized program is given an estimated energy cost, so the compiler can report not just whether a program compiles but roughly how expensive it is — and show that optimizations like constant folding and dead-code elimination measurably reduce that estimate. This cost model is illustrative, not a hardware measurement: loop iterations and recursion depth use fixed assumed counts rather than real analysis, if/else counts both branches as if they always run, and the Joules figure comes from an illustrative scaling constant chosen only to make the number human-readable.

The AST tab on this page is produced by a separate, independent parser built only for visualization, not the compiler's real lexer/parser — the panel itself flags it when the two disagree.
